# Meridiano Legal · Web canónica v2.28

Demo estática y autocontenida para GitHub Pages.

## Alcance

- Web pública comercial.
- Arquitectura de 8 servicios, 8 productos cerrados, 5 planes recurrentes y 6 documentos guiados.
- Portal demostrativo por perfiles: cliente, abogada y socio director.
- Datos completamente ficticios y persistencia limitada a la sesión del navegador.
- Identidad visual autocontenida, sin dependencias de imágenes externas.

## Publicación

El workflow `pages.yml` publica el contenido de `main` en GitHub Pages.

## Límites

Esta versión no es un backend productivo. No almacena archivos, no autentica usuarios reales, no envía formularios a una base de datos y no debe usarse con información confidencial.
