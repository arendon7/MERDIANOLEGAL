# Meridiano Legal — Design Foundation Decision Log

- Se adopta un orquestador local como autoridad de routing para skills de diseño.
- Skills externos quedan subordinados al canon, accesibilidad, performance y governance.
- No se vendoriza ni ejecuta ciegamente contenido remoto mutable.
- Se valida primero una muestra representativa antes de propagar cambios al sitio completo.
- El rediseño se tratará como problema de arquitectura/experiencia antes que como acumulación de CSS.
