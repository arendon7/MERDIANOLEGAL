# Meridiano Legal — Diseño y UX

Esta carpeta concentra la memoria humana del rediseño posterior a v5.31.

## Documentos

- `DESIGN-SKILLS-OPERATING-MODEL.md`: cómo se combinan los skills/lentes y en qué fase se usan.
- `EXTERNAL-SKILL-SOURCES.md`: procedencia, función y política de actualización de skills externos.
- `REDESIGN-AUDIT-TEMPLATE.md`: formato obligatorio para auditorías/iteraciones significativas.
- `INITIAL-REDESIGN-BACKLOG.md`: hipótesis iniciales de mejora; no equivale a una release aprobada.

## Regla

Ningún documento de esta carpeta sustituye fuentes canónicas de producto, catálogos, ADR, validadores o tests. El diseño debe mejorar la comprensión y la experiencia sin alterar la verdad jurídica/comercial ni las capacidades reales de la web.
